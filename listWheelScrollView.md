# Flutter 3D List with ListWheelScrollView

This Flutter project demonstrates the use of the `ListWheelScrollView` widget to create a 3D scrolling list. The widget provides a unique scrolling experience by placing list items in a cylindrical fashion, creating a 3D effect.

## What is ListWheelScrollView?

`ListWheelScrollView` is a specialized Flutter widget used to create a scrollable list of items arranged in a cylindrical or wheel-like pattern. It provides a 3D visual effect, making the items appear as if they are scrolling in and out of the screen. This widget is great for creating picker-style lists or unique scrolling experiences in your Flutter apps.

### Key Attributes of ListWheelScrollView:

1. **itemExtent**: 
   - Specifies the height (or extent) of each item in the list.
   - It is required and must be set to ensure consistent item sizing.
   
2. **children**: 
   - A list of widgets to be displayed as the items in the scrollable wheel.
   - Each child widget is placed in a scrollable list with the 3D effect.

3. **diameterRatio** (optional):
   - Controls the curvature of the cylinder.
   - A smaller value will give a more pronounced curve, while a larger value will flatten the curve.

4. **offAxisFraction** (optional):
   - Moves the wheel horizontally (off-axis).
   - Allows you to shift the list left or right.

5. **magnification** (optional):
   - Magnifies the center item to make it stand out when scrolling.
   - Useful for creating focus or picker effects.

6. **overAndUnderCenterOpacity** (optional):
   - Controls the opacity of items that are not in the center of the wheel.
   - Values range between 0.0 (fully transparent) and 1.0 (fully opaque).

### Usage of ListWheelScrollView

`ListWheelScrollView` is ideal for situations where you want to:
- Display a unique list with a 3D scrolling effect.
- Implement pickers (e.g., date pickers, time pickers).
- Enhance the user experience with an interactive visual effect for scrolling.
